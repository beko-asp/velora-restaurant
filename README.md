# VELORA — Modern Mediterranean Restaurant

A modern and responsive restaurant website designed as a portfolio project.

VELORA combines a premium visual identity with responsive design and interactive JavaScript features.

## Live Demo

https://beko-asp.github.io/velora-restaurant/

## Features

- Fully responsive design
- Modern dark & gold interface
- Interactive restaurant menu
- Menu category filtering
- Mobile navigation
- Scroll animations
- Active navigation indicator
- Restaurant gallery
- Reservation form validation
- Responsive layout for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Project Purpose

VELORA is a fictional restaurant website created to demonstrate front-end web development, responsive design and modern UI development skills.

The project does not represent a real restaurant or real reservation service.
